# Security Policy

## Scope

This repository contains analysis code, configuration, published public statistics and
synthetic data. It does not process real client, loan or savings records, and it must not
be used to do so. All loan-level data in it is generated.

## Reporting a vulnerability

If you find a security problem (for example a leaked credential, a vulnerable dependency,
or a workflow that could be abused), please report it privately through
[GitHub private vulnerability reporting](https://github.com/khalilurrrahmanridoykhan/mfi-portfolio-analytics/security/advisories/new)
instead of opening a public issue.

You can expect an acknowledgement within a few days. This is a small analysis project, so
there is no formal service level.

## Not a decision system

Results are model outputs based on published statistics and stated assumptions. They are
not for making credit, lending, supervisory or investment decisions.
